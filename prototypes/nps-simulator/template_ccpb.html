Read before believing it

  • This is association, not cause. Outlets that like CCPB tend to rate everything higher. The real gain from fixing something is probably smaller than shown.
  • Only outlets are Detractors, too few to model. So the model predicts Promoter against everyone else, and NPS changes are Promoter changes with the Detractor share held where it is. When service slips, some outlets would likely fall to Detractor too, so the losses shown are probably understated.
  • Overlapping questions are averaged into one area. The three rep questions correlate at about 0.8. Entered separately, one of them came out with the wrong sign.
  • Who the outlet is (channel, size, sales method, centre, office) did not improve prediction once ratings were known, so the model uses ratings only. Tested on held-out outlets: context alone , ratings alone , both (pseudo R squared, cross-validated). Context is used here to pick groups.
  • Missing answers (not asked or not answered) were set to the middle score for that question. Missing answers per area: .
  • Model: logistic regression, Promoter against the rest, fitted in scratch Python. A Turas build would use catdriver's R engine.
