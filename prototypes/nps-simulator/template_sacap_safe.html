What this file contains

    Hidden to protect small groups

    In each two-way breakdown, groups with fewer than the minimum are hidden, plus just enough other groups that the small ones cannot be worked out by subtraction. The page does not say which hidden groups are small.

      Read before believing it

      • This is association, not cause. Students who like SACAP rate everything higher, so real gains from fixing something are probably smaller than shown. Value for money behaves partly like a second measure of the same feeling.
      • The ratings overlap, so the ranking of areas is steadier than any single figure.
      • The checks cover subtraction within a table and between pairs of groups. Longer chains of sums across several tables are not checked; a full audit of those is a linear programming problem, which statistics offices run with specialist tools. Counts under the minimum inside a group are hidden. A zero gain can still show that nobody in a group needs a fix. That reveals no more than the rating tables for the same groups in the main report.
      • Model: ordinal logistic regression on Detractor, Passive and Promoter, weighted, fitted in scratch Python. A Turas build would use its R engine.
