# VAS derived variables — the exact calculation for every column

Generated from `vas_category_map.csv` and `vas_derived_config.R` by `run_vas_derive.R`. 273 columns.
Do not edit this file: change the map or the config and regenerate.

## Identity

### `ResponseID`

Alchemer's response id. Unit: id.

```
Taken as collected: the "Response ID" column in the export, or the response id from the API.
```

Source questions: Response ID

Missing and zero: Never missing.

### `ResponseStatus`

Whether Alchemer recorded the interview as Complete or Partial. Unit: text.

```
Taken as collected.
```

Source questions: Status

Missing and zero: A Partial reached fewer categories, and every category it never reached counts as a real zero. Use CategoriesAsked before comparing Partials with Completes.

## Income

### `IncomeBand`

The banded monthly household income answer, verbatim. Unit: text.

```
Taken as collected.
```

Source questions: Income

Missing and zero: Missing when the question was not answered.

### `IncomeMidpoint`

The band's midpoint, for share of wallet. Unit: rand per month.

```
Lookup on the Income question:
"Less than R3,500" -> 3,500
"R3,500 to R7,999" -> 5,750
"R8,000 to R21,999" -> 15,000
"R22,000 to R39,999" -> 31,000
"R40,000 to R74,999" -> 57,500
"More than R75,000" -> 100,000
"Decline to answer" -> missing (no share of wallet)
```

Source questions: Income

Missing and zero: Missing for "Decline to answer" and for a blank. NOTE: the bottom band's midpoint is set to its own ceiling, so share of wallet is understated for the lowest earners.

### `IncomeUpper`

The band's upper boundary, the alternative share-of-wallet base. Unit: rand per month.

```
Lookup on the Income question:
"Less than R3,500" -> 3,500
"R3,500 to R7,999" -> 7,999
"R8,000 to R21,999" -> 21,999
"R22,000 to R39,999" -> 39,999
"R40,000 to R74,999" -> 74,999
"More than R75,000" -> 100,000
"Decline to answer" -> missing (no share of wallet)
```

Source questions: Income

Missing and zero: Missing for "Decline to answer" and for a blank. The open-ended top band has no upper bound, so it carries the same value as its midpoint.

```

Source questions: all category statuses

```

Source questions: all category statuses

CategoriesIncomplete > 0
```

Source questions: CategoriesIncomplete

Missing and zero: Never missing. Exclude these respondents from share-of-wallet means if you want a clean base.

## Outliers

### `OutlierCells`

How many of this respondent's collected cells carry an implausibly large figure. Unit: count.

```
A collected cell is flagged when it exceeds its spend class's ceiling.
Transactions per month:
consumption: over 62 per month
obligation: over 10 per month
transfer: over 31 per month
received: over 31 per month
Monthly spend:
consumption: over 2e+04 rand
obligation: over 1e+05 rand
transfer: over 1e+06 rand
received: over 1e+06 rand
```

Source questions: every collected category cell

Missing and zero: Never missing. A flag NEVER changes a number - review the Audit sheet rows marked Outlier and decide whether to exclude the respondent in reporting.

### `OutlierFlag`

Whether any of this respondent's answers were flagged as implausible. Unit: TRUE/FALSE.

```
OutlierCells > 0
```

Source questions: OutlierCells

Missing and zero: Never missing. The respondent's numbers are UNCHANGED; the flag lets reporting exclude them from means.

```

Source questions: FlightIntlCount, FlightIntlReturn

Missing and zero: 0 when the respondent does not have this category. NEVER missing: the amount is imputed from the config rather than collected, so it cannot fail to parse.

### `FlightInternational_Total_SpendPerTxn`

What one International flights transaction costs, combined, as the survey asks a single question. Unit: rand per transaction.

```
legs x R7,500 per leg, where legs = 2 if FlightIntlReturn = "Return" and 1 if "One way".
Blank FlightIntlReturn is treated as 1 leg.
Imputed: the survey collects no amount for this category.
```

Source questions: FlightIntlCount, FlightIntlReturn

Missing and zero: Missing when there were no transactions. Otherwise always present, being an imputed rate rather than a reported amount.

### `LongDistanceBus_Total_TxnPerMonth`

How often the respondent buys or pays Long distance bus, combined, as the survey asks a single question. Unit: transactions per month.

```
LDBusCount / 12
The count question asks how many were bought in the past 12 months.
```

Source questions: LDBusCount, LDBusReturn

Missing and zero: 0 when LDBusCount is 0 or the question was not reached. Missing only if the count is not a number.
